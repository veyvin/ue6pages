## 📋 Overview (English)

Automated Unreal Engine plugin/module documentation generator.

This repository automates the generation of documentation for Unreal Engine plugins and modules. It uses:

- **GitHub Actions** for static discovery — plugin/module catalog pages, no AI in CI
- **Google Translate** for Chinese translations
- **Local backend AI** (any OpenAI-compatible API, configured in backend Settings) for《使用方法》(usage) docs, batch-generated on demand

### 🏗️ Architecture

```
┌─────────────────────────────────────────────────────────────────┐
│  Private Repo: veyvin/UnrealEngine                             │
│  └── Sync Fork (sync upstream) + Deploy Pages                  │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  Public Repo: veyvin/ue6pages (this one)                       │
│  └── Generate & Deploy UE Docs (daily 07:00 UTC)               │
│      ├─ Pull UE source (sparse checkout)                       │
│      ├─ Generate plugin/module static docs (no AI)             │
│      ├─ Translate to Chinese                                   │
│      └── Deploy to GitHub Pages                                │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
                   https://ue.veyvin.com
```

### ⚙️ Configuration

**Required Secrets**

| Secret | Description |
|--------|-------------|
| `PRIVATE_REPO_PAT` | Classic PAT with `repo` scope, to access veyvin/UnrealEngine |

**Optional Variables**

| Variable | Default | Description |
|----------|---------|-------------|
| `TRANSLATE_ENABLED` | `true` | Enable Chinese translation (Google Translate, not AI) |

AI usage docs are not generated by CI. Run the local backend (`backend/`), configure
your OpenAI-compatible endpoint in the frontend Settings page, then use
**AI 批量生成** to write《使用方法》docs in batch.

**GitHub Pages (Vue SPA)**

The live site is the Vue app in `frontend/`, not Jekyll. `gh-pages` only stores generated markdown and `assets/usage.fb`.

| Workflow | When | What it does to the live site |
|----------|------|-------------------------------|
| **Deploy GitHub Pages** | push `main`, or Run workflow | Builds `frontend/` and publishes it. Safe to run anytime. |
| **Generate & Deploy UE Docs** | daily 07:00 UTC, or Run workflow | Regenerates docs on `gh-pages`, then calls the Vue deploy. Does **not** publish Jekyll. |

Put Vue/backend source on **`main`**. Do not commit the SPA onto `gh-pages`.

**Manual Trigger Options**

- **Generate & Deploy UE Docs**: `force_regenerate`, `seed_from_private`
- **Deploy GitHub Pages**: rebuild the Vue site using the current `gh-pages` `usage.fb`

### 🚀 Getting Started

1. **Fork this repo** or clone it to your own account
2. **Configure Secrets**: Add `PRIVATE_REPO_PAT` in Settings
3. **Enable GitHub Pages**: Set Source to GitHub Actions
4. **Run Workflows**: Manually trigger with `seed_from_private` enabled

### 📊 Performance

| Workflow | Parallel | Time Limit | Daily Capacity |
|----------|----------|-----------|---------------|
| Generate UE Docs | 8 threads | 6h | ~1800 docs |

## 📋 概述 (中文)

自动化 Unreal Engine 插件/模块文档生成器。

本仓库自动化生成 Unreal Engine 插件和模块的文档，使用以下技术：

- **后端 AI（任意 OpenAI-compatible API，在前端设置页配置）** 批量生成《使用方法》文档
- **Google Translate** 用于中文翻译
- **GitHub Actions** 每日自动跑静态发现（CI 不调用任何 AI）

### 🏗️ 架构

```
┌─────────────────────────────────────────────────────────────────┐
│  私有仓库: veyvin/UnrealEngine                                  │
│  └── Sync Fork (同步上游) + Deploy Pages                        │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  公有仓库: veyvin/ue6pages (本仓库)                             │
│  └── Generate & Deploy UE Docs (每日 07:00 UTC)                 │
│      ├─ 拉取 UE 源码 (sparse checkout)                         │
│      ├─ 静态生成插件/模块目录（无 AI）                       │
│      ├─ 翻译为中文                                             │
│      └── 部署到 GitHub Pages                                   │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
                   https://ue.veyvin.com
```

### ⚙️ 配置

**必需的 Secrets**

| Secret | 说明 |
|--------|------|
| `PRIVATE_REPO_PAT` | 具有 `repo` 权限的 Classic PAT，用于访问 veyvin/UnrealEngine |

**可选变量**

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `TRANSLATE_ENABLED` | `true` | 启用中文翻译（Google Translate，非 AI） |

《使用方法》文档不由 CI 生成：启动本地后端（backend/），在前端设置页配置
OpenAI-compatible 接口，然后使用「AI 批量生成」。

**GitHub Pages（Vue 站点）**

线上是 `frontend/` 打出来的 Vue，不是 Jekyll。`gh-pages` 只存 markdown 和 `assets/usage.fb`。

| Workflow | 何时 | 会不会盖掉线上 Vue |
|----------|------|-------------------|
| **Deploy GitHub Pages** | push `main`，或手动 Run | 构建并发布 Vue。随时可跑。 |
| **Generate & Deploy UE Docs** | 每天 07:00 UTC，或手动 Run | 只更新 `gh-pages` 数据，再调用上面的 Vue 发布。不再发 Jekyll。 |

源码提交到 **`main`**，不要把 SPA 推进 `gh-pages`。

**手动触发选项**

- **Generate & Deploy UE Docs**: `force_regenerate`（强制重新生成）, `seed_from_private`（从私有仓库初始化）
- **Deploy GitHub Pages**: 用当前 `gh-pages` 上的 `usage.fb` 重新发布 Vue 站

### 🚀 快速开始

1. **Fork 本仓库**或克隆到自己的账号
2. **配置 Secrets**: 在 Settings 中添加 `PRIVATE_REPO_PAT`
3. **启用 GitHub Pages**: 将 Source 设置为 GitHub Actions
4. **运行 Workflows**: 手动触发并启用 `seed_from_private`

### 📊 性能指标
